# ShiftExifTime

Скрипт на PowerShell массового изменения (сдвига) времени у фотографий Canon (.CR3 и .JPG) на заданное количество часов. Время изменяется в EXIF-дат и файловом атрибуте Modified date. Полезно для коррекции времени съёмки при смене часового пояса.

## Файлы:

- **ShiftExifTime.ps1** — PowerShell-скрипт.
- **ShiftExifTime.cmd** — для вызова PowerShell-скрипта с нужными параметрами.
- **exiftool.exe** — утилита ExifTool (последней версии), должна лежать рядом со скриптом.

## Логика работы

1. Проверяется обязательный параметр `-HoursOffset`. Если не задан — скрипт выводит предупреждение и выходит без изменений.

2. Находится `exiftool.exe` в каталоге скрипта. При отсутствии — ошибка.

3. Формируется строка смещения времени в формате `H:00:00`.

4. Для каждого файла с расширением `.cr3` и `.jpg` в целевой папке (без рекурсии) делается единый вызов ExifTool:
   
   exiftool -AllDates+=<H:00:00> -FileModifyDate+=<H:00:00> -overwrite_original <файл>

```
— эта операция сдвигает:
- EXIF-теги DateTimeOriginal, CreateDate и ModifyDate  
- файловый атрибут Modify date (FileModifyDate / LastWriteTime)  
и перезаписывает оригинал без резервной копии.

## Требования

- Windows PowerShell ≥ 5.1  
- `exiftool.exe` (любая свежая версия) рядом со скриптом  
- Требуется разрешение на выполнение скриптов powershell
  Set-ExecutionPolicy -Scope Process Bypass
```

## Параметры

- **-HoursOffset** (int) — обязательный. Смещение времени в часах (может быть отрицательным).  
- **-TargetFolder** (string) — необязательный. По умолчанию - исходная папка с файлами.

## Способы использования

```
# Сдвинуть на +2 часа в текущей папке
ShiftExifTime.ps1 -HoursOffset 2

# Сдвинуть на –1 час в указанной папке
ShiftExifTime.ps1 -HoursOffset -1 -TargetFolder "C:\Photos"
```

## Особенности

- **Единый вызов** ExifTool меняет и EXIF-теги, и файловый штамп.
- Оригинальные файлы перезаписываются без создания резервных копий (`-overwrite_original`).
- Если нужно изменить рекурсивно по подпапкам, можно добавить `-Recurse` к команде `Get-ChildItem` внутри скрипта.
