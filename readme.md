# ShiftExifTime

Скрипт на PowerShell для массового сдвига времени у фотографий Canon (`.CR3`, `.JPG`, `.JPEG`). Время меняется в EXIF-датах и файловом атрибуте Modified date. Полезно для коррекции времени съемки после поездок и смены часового пояса.

Проект нужен для приведения фотографий из разных устройств к одной правильной временной шкале. Типичный сценарий: часть снимков сделана телефоном, который получает точное время и часовой пояс из сети, а часть — фотоаппаратом с внутренними часами. У фотоаппарата может быть не только неверный часовой пояс, но и небольшой уход времени вперед или назад.

Скрипт позволяет вручную посчитать нужную поправку и применить ее ко всей серии снимков: сдвинуть часы, минуты и секунды, а при необходимости дополнительно записать новый часовой пояс в EXIF. Это помогает получить корректную сортировку снимков по времени съемки в Lightroom и других программах.

## Зачем этот скрипт

Скрипт решает несколько практических задач, которые возникают после поездок и съемки на разные устройства:

- выравнивает время фотоаппарата по эталонному снимку с телефона;
- компенсирует ошибку внутренних часов фотоаппарата, если они немного убежали вперед или отстали;
- позволяет корректировать не только часы, но и минуты с секундами;
- оставляет изменение часового пояса необязательным, потому что Lightroom обычно сортирует по видимому времени съемки, но другие программы могут учитывать EXIF offset-поля;
- делает опасную операцию чуть безопаснее за счет явного подтверждения перед изменением файлов.

## Что делает этот скрипт

- находит фотографии поддерживаемых форматов в выбранной папке;
- сдвигает `DateTimeOriginal`, `CreateDate`, `ModifyDate` и `FileModifyDate`;
- складывает `HoursOffset`, `MinutesOffset` и `SecondsOffset` в один итоговый сдвиг, поэтому у каждого параметра может быть свой знак;
- при указании `TimeZoneOffset` записывает новый часовой пояс в `OffsetTime`, `OffsetTimeOriginal` и `OffsetTimeDigitized`;
- вызывает локальный `exiftool.exe` и перезаписывает оригинальные файлы без резервных копий.

## Файлы

- **ShiftExifTime.ps1** — основной PowerShell-скрипт.
- **ShiftExifTime.cmd** — удобный запуск с заранее заданными параметрами.
- **exiftool.exe** — утилита ExifTool, должна лежать рядом со скриптом.

## Логика работы

1. Скрипт принимает смещение по часам, минутам и секундам.
2. Все компоненты складываются в один итоговый сдвиг. Смешанные знаки обрабатываются корректно: `-HoursOffset 1 -MinutesOffset -30` означает итоговые `+30` минут.
3. Если указан `-TimeZoneOffset`, скрипт выставляет новый часовой пояс в EXIF-полях `OffsetTime`, `OffsetTimeOriginal` и `OffsetTimeDigitized`. По умолчанию часовой пояс не меняется. Изменение `-TimeZoneOffset` является факультативным, так как Лайтрум не учитывает его при сортировке обработке фотографий. Сделано на случай изменения логики Lightroom или наличие данной логики в каких-то других будущих программах. 
4. Находится `exiftool.exe` в каталоге скрипта. При отсутствии будет ошибка.
5. Для каждого файла с расширением `.cr3`, `.jpg` или `.jpeg` в целевой папке (без рекурсии) делается единый вызов ExifTool:

```powershell
exiftool -AllDates+=<h:mm:ss> -FileModifyDate+=<h:mm:ss> -overwrite_original <файл>
```

Для отрицательного итогового сдвига используется оператор `-=` вместо `+=`.

Эта операция сдвигает:

- EXIF-теги `DateTimeOriginal`, `CreateDate` и `ModifyDate`;
- файловый атрибут Modify date (`FileModifyDate` / `LastWriteTime`);
- при указании `-TimeZoneOffset` — EXIF-поля часового пояса;
- оригинальный файл перезаписывается без резервной копии.

## Требования

- Windows PowerShell 5.1 или новее.
- `exiftool.exe` рядом со скриптом.
- Разрешение на выполнение скриптов PowerShell, например:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## Параметры

- **-HoursOffset** / **-Hours** (int) — смещение в часах.
- **-MinutesOffset** / **-Minutes** (int) — смещение в минутах.
- **-SecondsOffset** / **-Seconds** (int) — смещение в секундах.
- **-TimeZoneOffset** / **-TZ** (string) — новый часовой пояс в формате `+08:00` или `-03:30`. Если не указан, часовой пояс не меняется.
- **-TargetFolder** (string) — папка с файлами. По умолчанию текущая папка.

Нужно указать хотя бы один параметр действия: смещение времени или `-TimeZoneOffset`. Если итоговое смещение равно нулю и часовой пояс не указан, скрипт ничего не меняет.

## Способы использования

```powershell
# Сдвинуть на +2 часа в текущей папке
.\ShiftExifTime.ps1 -HoursOffset 2

# Сдвинуть на -1 час в указанной папке
.\ShiftExifTime.ps1 -HoursOffset -1 -TargetFolder "C:\Photos"

# Сдвинуть на +2 часа 15 минут
.\ShiftExifTime.ps1 -HoursOffset 2 -MinutesOffset 15

# Сдвинуть назад на 45 секунд
.\ShiftExifTime.ps1 -SecondsOffset -45

# Смешанные знаки: итоговый сдвиг будет +30 минут
.\ShiftExifTime.ps1 -HoursOffset 1 -MinutesOffset -30

# Сдвинуть время и выставить часовой пояс +08:00
.\ShiftExifTime.ps1 -HoursOffset 5 -MinutesOffset -4 -SecondsOffset 10 -TimeZoneOffset "+08:00"

# Только выставить часовой пояс, не меняя время съемки
.\ShiftExifTime.ps1 -TimeZoneOffset "+08:00"
```

## Быстрый запуск через CMD

В `ShiftExifTime.cmd` можно поменять значения в начале файла:

```bat
set "HOURS_OFFSET=2"
set "MINUTES_OFFSET=0"
set "SECONDS_OFFSET=0"
set "TIME_ZONE_OFFSET="
```

Чтобы вместе со сдвигом выставить часовой пояс, заполните `TIME_ZONE_OFFSET`, например `+08:00`.

После этого можно запускать `.cmd` двойным кликом.

## Особенности

- Перед изменениями скрипт спрашивает подтверждение.
- Единый вызов ExifTool меняет и EXIF-теги, и файловый штамп.
- Оригинальные файлы перезаписываются без создания резервных копий (`-overwrite_original`).
- Если нужно изменить файлы рекурсивно по подпапкам, можно добавить `-Recurse` к команде `Get-ChildItem` внутри скрипта.
